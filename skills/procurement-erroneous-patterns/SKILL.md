# 政府採購錯誤行為態樣 Agent Skill 檢核準則

## 一、技能定位與適用時機
本 Agent Skill 專供「政府採購AI領航員平台 V2.0」階段三【監察查核領航】之 AI 代理（`AuditInvestigatorAgent`）及稽核／查核／監察人員使用。凡遇下列情境，應自動啟動本檢核準則：
1. 招標文件、施工規範、預算書、契約條款之事前防弊與適法性審查。
2. 開標、審標、決標紀錄及評選／審查委員會會議紀錄之採購稽核。
3. 工程施工查核、履約管理、契約變更、驗收與付款作業之缺失比對。
4. 廠商異議、申訴審議判斷、履約爭議調解案件及監察院／政風調查報告之缺失歸因與知識管理（KM）自動標註。

## 三、AI Agent 檢核執行標準作業程序 (SOP)
1. **範圍識別**：依輸入案件之採購金額（15萬以下／15萬~150萬／150萬以上／查核／巨額）、招標方式（公開招標／限制性招標第22條／評分及格最低標）及工程特性，自動權重調用對應準則模組。
2. **多維規則比對**：
   - 檢核文本特徵、關鍵違失條款、數據門檻（如追加逾 50%、等標期不足、15 萬元分批化整為零、未加註「或同等品」、ISO 9000 誤置資格／規格、評分及格最低標納標價評分等）。
   - 結合稽核人員互動勾選之實務查核項目。
3. **風險等級評定**：
   - `CRITICAL`（重大違法／涉綁標、圍標、不法限制競爭、違法分批、程序無效、涉刑責或監察糾正風險）
   - `HIGH`（顯著程序瑕疵／違反採購法強制規定、恐致申訴撤銷原處分或稽核重大缺失）
   - `MEDIUM`（行政疏失／紀錄記載不全或作業未盡周延，應限期改善）
4. **輸出與知識管理迴圈**：
   - 產出結構化檢核報告（含命中準則編號、態樣內容、相關法令及函釋、具體因應／導正措施）。
   - 同步提供知識管理（KM）標籤，供異議／申訴／調解及查核調查報告寫入累積庫，強化機關跨案防弊預警能力。
